# ANONYMIZER
ANONYMIZER - Crypto Privacy Optimizer

<img width="640" height="204" alt="grafik" src="https://github.com/user-attachments/assets/1f36a80a-a462-4797-b3ba-cb870a45a933" />

Requirements:
- Windows 10 or 11 required (the .py file in the installation folder also runs on Linux)

Main Features:
- Supports all major cryptocurrencies
- Our algorithm uses more than 1,248 methods in real time to find the
  optimal route for anonymization!
- Calculates the best route to anonymize your cryptocurrencies,
  concealing their origin
- Fully customizable
- Displays an anonymity score and estimated network fees in
  real time
- Supports several thousand wallets simultaneously, including bulk
  wallet creation, management, and login!

Free to use!
